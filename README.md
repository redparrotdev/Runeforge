# 🔥 Runeforge

> A 2D game engine forged with MonoGame

Runeforge is a minimalist pet-project game engine that sits on top of MonoGame. Currently in early development 🔧

## ✨ Features

- **Entity Component System** - Hand-crafted ECS
- **Sprite Management** - Tools and components for easy-to-use sprite and 2d animations handling
- **Input Handling** - Keyboard, mouse, and gamepad support out of the box with virtual inputs configuration.
- **Scene System** - Organizes game into manageable scenes
- **Per-scene content management**
- **Coroutines** - Hand-crafted coroutine system
- **Debugging tool** - Integrated with Dear ImGui for real-time debugging and visualization.
- **Basic 2D Physics** - Simple physics system for collision detection and response via components.
- **2D Camera** - camera implementation with different viewport adapters, for different scenarios.

## 🚀 Quick Start
For now, use it as is inside your MonoGame project.

## 🛠️ Tech Stack

- .NET 8 / .NET 9
- MonoGame Framework

## 📦 Installation

Currently, Runeforge is not available as a package. To use it in your project, clone the repository and include the source files in your MonoGame project.
